# 安置帮教智能台账系统

> 面向基层司法所的安置帮教人员信息化管理平台

## 功能一览

| 模块 | 功能 |
|------|------|
| 人员台账 | 增删改查、33字段、身份证自动推算性别/生日 |
| 搜索筛选 | 综合搜索 + 高级筛选（罪名/责任人/年龄范围） |
| 走访记录 | 走访登记、时间轴展示、异常标记 |
| 走访频率 | 预设5档（月/季/半年/年）+ 自定义天数 |
| 提醒系统 | 到期分级提醒（7天/30天/超期）、走访超期、季度归档倒计时 |
| 仪表盘 | 状态统计、风险分布、本月新增、责任人分布、待办事项 |
| OCR扫描 | 身份证/姓名/罪名/刑期自动识别，支持PDF多页 |
| 季度报表 | 在册/新增/走访完成率，一键查看 |
| Excel导出 | 人员列表导出（支持筛选条件） |
| 安全 | 身份证脱敏显示、首次强制改密码、JWT认证 |

## 快速开始

### Windows

1. 确保已安装 [Python 3.10+](https://www.python.org/downloads/)（安装时勾选 "Add Python to PATH"）
2. 双击 `start.bat`
3. 浏览器打开 http://localhost:8000
4. 用 `admin` / `admin123` 登录
5. **首次登录会强制要求修改密码**

### Linux / macOS

```bash
# 确保已安装 Python 3.10+
bash start.sh
# 浏览器打开 http://localhost:8000
```

### 手动启动

```bash
cd judicial-system/backend
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -i https://pypi.tuna.tsinghua.edu.cn/simple -r requirements.txt
cp .env.example .env
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

## 使用指南

### 录入人员

1. 点击「+ 新增人员」
2. 第一步：填写姓名、身份证号（自动推算性别和生日）
3. 第二步：填写帮教信息（罪名、期限、责任人、风险等级）
4. 第三步：填写家庭信息（可选）
5. 点击「确认入库」

### OCR扫描入库

1. 点击「📷 OCR扫描」
2. 拖入扫描件（JPG/PNG/PDF）
3. 点击「开始识别」
4. 核对识别结果，修改错误字段
5. 点击「确认入库」

### 录入走访记录

1. 在人员台账中点击某人 → 打开详情侧边栏
2. 切换到「走访记录」Tab
3. 点击「+ 新增走访」
4. 填写走访日期、方式、内容
5. 如有异常，打开「有无异常」开关并填写详情

### 设置走访频率

1. 打开人员详情侧边栏
2. 在「帮教信息」区域找到「走访频率」
3. 点击 ✏️ 按钮
4. 选择预设方案（月/2月/季/半年/年）或自定义天数

### 查看待办提醒

打开系统首页（仪表盘），顶部显示：
- 🔴 7天内到期人数
- 🟡 30天内到期人数
- ⚠️ 超期未走访人数
- 📋 季度归档倒计时

点击可跳转到对应列表。

### 高级筛选

1. 在人员台账页面点击「高级筛选」
2. 可按罪名、责任人、年龄范围组合筛选
3. 点击「筛选」生效，「重置」清空条件

### 导出Excel

1. 在人员台账页面点击「📥 导出」
2. 如需筛选后导出，先设置筛选条件再点导出
3. 浏览器自动下载 Excel 文件

### 查看身份证号

- 默认脱敏显示：`320102********1234`
- 点击表头的 👁️ 按钮切换为完整显示
- 再点 🙈 恢复脱敏

## 常见问题

**Q: 启动后浏览器打不开？**
A: 检查端口 8000 是否被占用，或修改 `.env` 中的端口配置。

**Q: OCR识别不准？**
A: 确保扫描件清晰、不歪斜。手写内容识别率低，需手动修改。

**Q: 忘记密码？**
A: 删除 `data.db` 文件，重启服务会重建默认账号。

**Q: 如何备份数据？**
A: 复制 `data.db` 文件和 `uploads/` 目录到安全位置。

**Q: 其他电脑能访问吗？**
A: 可以。启动后用本机IP访问，如 `http://192.168.1.100:8000`，确保防火墙放行 8000 端口。
